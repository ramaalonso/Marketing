# 📁 Galería de Imágenes de Yerbazo (`/img`)

Sube aquí tus fotos (`.webp`, `.png`, `.jpg`) desde GitHub o desde tu PC.
La plataforma **Yerbazo Holo IA** detecta automáticamente cualquier imagen que subas a esta carpeta o sus subcarpetas:

- `/img/mates/` → Mates Imperiales, Torpedos, Camioneros y Bombillas.
- `/img/productos/` → Paquetes de yerba, latas, yerberas, picos y combos.
- `/img/cebadas/` → Fotos de mates ya preparados, montañitas, espuma o estilo de vida.
